# Exercícios de HTML e CSS

Este repositório reúne atividades práticas desenvolvidas durante meus estudos de desenvolvimento web.

## Projetos

### 1. Currículo Pessoal
Projeto desenvolvido para praticar a criação de uma página web com HTML.

**Conteúdos praticados:**
- Estrutura básica de um documento HTML.
- Inserção de imagens e links.
- Organização de informações em uma página web.

### 2. Avaliação de HTML
Atividade acadêmica composta por três páginas web interligadas: uma página sobre o Mercosul, uma tabela de fusos horários da América do Sul e um formulário de dados pessoais.

**Conteúdos praticados:**
- Títulos, parágrafos e listas ordenadas e não ordenadas.
- Links entre páginas e para sites externos.
- Inserção de imagens.
- Criação de tabelas HTML.
- Campos de formulário, caixas de seleção e listas suspensas.
- Formatação visual com CSS.
- Organização de arquivos em um projeto web.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Praticar os fundamentos do desenvolvimento web, desenvolver minha autonomia na programação e registrar minha evolução durante o aprendizado.
