## 📂 Projetos

### 01. 📄 Currículo Pessoal

Projeto desenvolvido para praticar a criação de uma página web utilizando HTML.

**Conhecimentos aplicados:**
- Estrutura básica de um documento HTML.
- Inserção de imagens e links.
- Organização de informações em uma página web.

---

### 02. 🌎 Avaliação de HTML

Atividade acadêmica composta por três páginas interligadas: uma página sobre o Mercosul, uma tabela de fusos horários da América do Sul e um formulário de dados pessoais.

**Conhecimentos aplicados:**
- Títulos, parágrafos e listas ordenadas e não ordenadas.
- Links internos e externos.
- Inserção de imagens.
- Criação e estruturação de tabelas.
- Campos de formulário, caixas de seleção e listas suspensas.
- Formatação visual com CSS.
- Organização de arquivos em um projeto web.

---

### 03. 🎓 Divs e HTML Semântico — TechCursos

Desenvolvimento de uma página web fictícia para a plataforma TechCursos, utilizando HTML e CSS, seguindo um modelo proposto em atividade acadêmica.

**Conhecimentos aplicados:**
- Estruturação de páginas com HTML.
- Utilização de divs e classes.
- Organização de conteúdo em seções.
- Estilização com CSS externo.
- Cores, tipografia, margens e espaçamentos.
- Bordas e arredondamento de elementos.
- Criação e utilização de favicon.
- Organização de cabeçalho, menu, conteúdo e rodapé.
